# ss-096 바이브 디자인 랩

매일 **Grok이 리서치한 레퍼런스**를 보고 웹디자인 연습하는 사이드 프로젝트.

설치 없음. HTML 열면 됨.

```
open index.html
```

## 루프

1. Grok한테 “오늘 레퍼런스 리서치해줘” (또는 Grok Bot이 던져준 링크)
2. `days/YYYY-MM-DD/` 만들고 `brief.md`에 레퍼런스 메모
3. 같은 폴더 `index.html`에 바이브코딩으로 따라 만들기
4. 갤러리(`index.html`)에 하루가 쌓임

완벽한 클론 아님. **톤·레이아웃·타이포·여백** 감각 익히기.

```
days/YYYY-MM-DD/
  brief.md      # 레퍼런스 URL, 왜 뽑았는지, 훔칠 포인트

```
